# Addon Index

The `FreeCAD/Addons` repository is home to the metadata of the official index of registered addons.

It contains a list of all known addons and their sources as well as related data like what Python packages can be installed as dependencies.

The remote addon cache at [addons.freecad.org][Cache] is updated every four hours by the Addon Manager's [AddonCatalogCacheCreator.py][Cache script], so changes to the index will not be reflected in the Addon Manager until that script has been run to update the remote cache.
